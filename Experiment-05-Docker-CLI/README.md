Experiment 5: Docker CLI Commands

Aim:
To study and execute basic Docker CLI commands for managing Docker images and containers.

Software Required:
1. Docker Desktop or Docker Engine
2. Command Prompt or Terminal

Commands:
1. docker --version
2. docker info
3. docker images
4. docker pull hello-world
5. docker run hello-world
6. docker ps
7. docker ps -a
8. docker stop CONTAINER_ID
9. docker start CONTAINER_ID
10. docker rm CONTAINER_ID
11. docker rmi IMAGE_NAME

Result:
Basic Docker CLI commands were executed and studied.
